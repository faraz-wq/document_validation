How it works:
  1. Select the type of certificate you want to validate
  2. Upload the required documents (PDF, JPG, JPEG, PNG)
  3. Optionally provide custom names for the documents
  4. Click 'Process Documents' to run the validation workflow

The system will perform two-stage processing:

  • Stage 1: Individual document digitization and extraction
  • Stage 2: Cross-document summary and validation
